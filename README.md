# 📘 منصة تفاعلية للوحدة الثالثة — الصف الخامس (صفحات ٥٤–٦١)

## 🎯 الهدف
تطوير منصة تعليمية تفاعلية لطلاب الصف الخامس، تغطي أنشطة الصفحات ٥٤–٦١ من كتاب الرياضيات، مع دعم التمارين التلقائية، التصحيح الفوري، الشرح خطوة بخطوة، وامتحان نهائي بدرجة ٢٠.

## ✨ الميزات
- **تمارين من الكتاب**: أنشطة مأخوذة مباشرة من الصفحات ٥٤–٦١.
- **وضع حر**: توليد أمثلة جديدة تلقائيًا (ضرب، قسمة، وضع الفاصلة، مسائل نصية).
- **تصحيح فوري**: التحقق من الإجابة وإعطاء تغذية راجعة مباشرة.
- **زر "اطلب الحل"**: يعرض خطوات الحل بشكل آلي ومنظم.
- **تلميحات ذكية**: تظهر عند الخطأ أو عند الطلب.
- **امتحان نهائي**: ٢٠ سؤالًا مع تقرير درجة نهائية من ٢٠.
- **ملخص الأداء**: عدد المحاولات، الصحيحة، الخاطئة، ومراجعة آخر ٥ أسئلة.
- **حفظ واستعادة التقدم**: باستخدام LocalStorage.
- **دعم الأرقام العربية والغربية**.
- **قراءة صوتية**: للأسئلة والتغذية الراجعة.

## 🛠️ التقنية المستخدمة
- **HTML/CSS/JavaScript** للواجهة التفاعلية.
- **Streamlit + Python** لنشر التطبيق عبر السحابة.
- **Streamlit Components** لدمج واجهة HTML داخل تطبيق Python.
